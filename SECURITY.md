# Security policy

Please do not disclose security vulnerabilities, credentials, personal data,
or production configuration in a public issue.

Report vulnerabilities privately to security@femres.org. Include the affected
URL or component, reproduction steps, expected impact, and any suggested
mitigation. FemRes will acknowledge valid reports and coordinate disclosure
after a fix is available.

The public repository is a sanitized snapshot. If you find personal data or a
secret in the repository or its history, treat it as a security incident and
contact security@femres.org immediately.
